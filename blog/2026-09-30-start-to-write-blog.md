## 為什麼開始寫 blog?

會開始寫 blog 完全是受到 [Wiwi.Blog](https://wiwi.blog/) 的啟發。加上我發現我蠻愛碎碎念的，但是又不想要造成別人的困擾，那乾脆用 blog 的形式來排解碎碎念的衝動。開始寫部落格好像自己也會對更注意日常發生的事情 (才不會沒梗寫 blog)。


## 我用的工具

幾乎沒有什麼門檻阿！想要寫 blog 的大家一定要試試阿！
- [Docusaurus](https://docusaurus.io/)：是由 Facebook 推出的開源靜態網站生成工具，主要設計是用來放文件的。
- [GitHub Pages](https://pages.github.com/)：是 GitHub 提供的靜態網站託管服務
- [GitHub Action]()：抄 Docusaurus 官方的 [workflow file](https://docusaurus.io/docs/deployment#triggering-deployment-with-github-actions)。
